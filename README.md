## What I've built

**[ATS Resume Analyzer](https://github.com/Izzahsheikh/ATS-Resume-Analyzer)**  
Checks how well a resume matches a job description. Built it because I was applying to jobs and had no idea why I kept getting filtered out.

**[AI Research Assistant](https://github.com/Izzahsheikh/AiResearchAssistant)**  
Helps with summarizing and navigating research papers. Useful when you're drowning in PDFs.

**[Sarcasm Detector](https://github.com/Izzahsheikh/MiniSarcasmDetector)**  
NLP classifier. Small project, but it was my first time properly working with text classification.

**[English Grammar Corrector](https://github.com/Izzahsheikh/EnglishGrammerCorrector)**  
Grammar correction using NLP. Does what it says.

**[University Event Management System](https://github.com/Izzahsheikh/UniversityEventManagementSystem)**  
Full-stack app for managing campus events. JavaScript on the frontend.
